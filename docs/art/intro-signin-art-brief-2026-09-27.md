## North star

First paint must feel like **arriving in São Paulo in autumn afternoon** — Praça canopy, padaria amber, soft sky — then a calm email+password card that still belongs in that world.

Not: bland SaaS login, white Stripe form, Habbo candy splash, neon cyber city, generic “Latin town” postcard.

Feel: title-screen wow → one breath → sign-in. Guest CTA secondary. Same warmth as Padaria impressive hold.

---

## Sequence (visual)

1. **Title / intro beat (2–4s or skippable)**  
   - Hero: isometric Praça silhouette (fountain / trees / soft-sky `#A8C5D4`) OR Padaria storefront (awning terracotta `#C45C26`, glass-cool case) — pick **one** hero; don’t collage both equally.  
   - Preferred hero: **Praça late-afternoon** with Padaria awning readable in mid-ground (sells the world).  
   - Wordmark **Tudo Bem** + warm sun mark (existing logo OK). Tagline short PT-primary (Product/Curriculum copy).  
   - Light: soft warm key from left (palette lighting). Autumn leaves as soft particles or static canopy — subtle, not storm.

2. **Sign-in / register card**  
   - Floats over the same world scene (dimmed soft veil, **not** hard black or flat white void).  
   - Card: cream-wall `#F5E6D3` fill, wood-warm or charcoal text, terracotta/mustard primary button.  
   - Fields: email, password; register secondary; optional “I am 18+” checkbox (Product).  
   - Guest “Explorar” / enter world = ghost or secondary, still warm.  
   - Errors: polite, no red screaming SaaS.

3. **Idle-kick interstitial (same visual family)**  
   - Calm “Volte quando quiser” over soft Praça/Padaria still — same card language. Not a ban screen.

## Must / Don’t

| Must | Don’t |

| SP autumn + Praça/Padaria silhouette readable at 390 | Flat white / grey login void |

| Cream / terracotta / mustard / soft-sky from palette | Neon magenta/cyan, sterile blue SaaS |
| Primary CTA thumbable full-width on mobile | Tiny centered Stripe clone |
| Logo + PT-first hierarchy | English-only corporate splash |
