# Phase 0 Palette

São Paulo warmth — concrete, terracotta, trees, padaria amber. Not Habbo candy, not washed pastel, not generic “Latin town.”

## Core
| Token | Hex | Use |
|-------|-----|-----|
| cream-wall | `#F5E6D3` | Interior walls, kitnet plaster |
| terracotta | `#C45C26` | Accents, padaria awning, door frames |
| mustard | `#D4A017` | Signage highlights, warm lamps |
| sp-green | `#2F5D50` | Verde plates, plant canopy, nameplate Verde |
| soft-sky | `#A8C5D4` | Praça sky / late afternoon wash |
| charcoal-ui | `#2C2C2C` | UI chrome, readable text |
| concrete | `#9A9A92` | Praça paving, building faces |
| mural-coral | `#E07A5F` | One mural accent wall (Praça) |
| glass-cool | `#C5D5DE` | Padaria display case |
| wood-warm | `#8B5E3C` | Counter, chairs, kitnet floor trim |
| sea-teal | `#3FA9A0` | Praia: the sea, the Praia chapter of the Diário, the party boat pill |
| sand | `#EBD9A8` | Praia: the sand terrain and the beach details |
| lagoon | `#3D8073` | Lagoa do Jerivá: the fresh water terrain (`w`), darker and greener than the sea |

## Lighting
- Praça: soft late-afternoon (slight warm key from left)
- Padaria: morning warm interior, cooler glass reflections
- Kitnet: neutral daylight through painted street window

## Avoid
Neon magenta/cyan, pure white sterile walls, cartoon primary rainbow, chibi oversaturation.
